# GONE 커밋 메시지 규칙

## 형식

```text
타입: 제목 (#이슈번호)

본문 (선택)
```

## 타입

| 타입 | 용도 |
|---|---|
| `feat` | 새 기능 |
| `fix` | 버그 수정 |
| `ui` | 기능 변경 없는 UI 수정 |
| `refactor` | 기능 변경 없는 구조 개선 |
| `test` | 테스트 추가·수정 |
| `docs` | 문서 추가·수정 |
| `chore` | 설정·도구·의존성 변경 |
| `hotfix` | 운영 긴급 수정 |

## 규칙

- 제목은 한국어, 50자 이내, 마침표 없이 명령형으로 작성합니다.
- 하나의 커밋에는 하나의 논리적 변경만 담습니다.
- 기능·수정 작업은 관련 이슈 번호를 포함합니다.
- 작업 중 커밋은 Push 전 의미 있는 단위로 정리합니다.

## 예시

```bash
docs: GONE 개발 문서 체계 추가
feat: 실습실 예약 목록 조회 추가 (#12)
ui: 외출 승인 상태 배지 조정 (#18)
fix: 외출 복귀 처리 후 상태 갱신 수정 (#31)
```
