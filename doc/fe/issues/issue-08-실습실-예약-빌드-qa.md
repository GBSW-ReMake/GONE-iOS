## 구현 확인

- 실습실 탭의 `준비 중인 기능` 플레이스홀더를 실제 예약 화면으로 교체했습니다.
- 4층·3층·2층 전환, 실습실 선택 테두리, 선택 전후 예약 CTA 상태를 구현했습니다.
- 대표자·사용 인원 명단·사용 목적을 모두 입력했을 때만 신청 CTA가 활성화됩니다.
- 신청 완료 후 상세 카드·신청 상태 타임라인을 표시하며, 홈의 실습실 신청 카드에도 신청 시간과 상태가 반영됩니다.

## 정적 검증

- `swiftc -parse`로 전체 Swift 소스의 문법 검증을 통과했습니다.
- `git diff --check`로 공백 오류가 없음을 확인했습니다.

## 빌드 검증 제한

- iOS Debug 빌드는 현재 실행 환경의 CoreSimulatorService에 사용 가능한 Simulator runtime이 없어 Asset Catalog 컴파일 단계에서 실패했습니다.
- Swift 컴파일 시작 전후의 환경 오류이며, 기능 코드의 컴파일 오류는 출력되지 않았습니다.
- Xcode에서 iPhone 시뮬레이터 또는 실기기로 아래 시나리오를 확인해야 합니다.

## 수동 QA 시나리오

1. 실습실 탭에서 4층·3층·2층 목록이 전환되는지 확인
2. 실습실 미선택 시 회색 CTA, 선택 시 파란 테두리와 활성 CTA 확인
3. 신청 폼의 세 항목 중 하나라도 비우면 CTA가 비활성인지 확인
4. 세 항목 입력 후 신청 시 완료 카드와 신청 상태 타임라인 확인
5. 홈으로 돌아가 실습실 신청 카드의 시간·상태 갱신 및 카드 탭 이동 확인

## API 연동 전 제한사항

- 목록·예약·상태는 `MockLabReservationRepository`의 메모리 데이터입니다. 앱 재실행 시 신청 상태는 초기화됩니다.
- 실제 대표자 자동 입력, 인원 정원·중복 시간 검증, 교사 승인·반려, 취소 API 및 취소 확인 다이얼로그는 API 계약 후 연결합니다.
