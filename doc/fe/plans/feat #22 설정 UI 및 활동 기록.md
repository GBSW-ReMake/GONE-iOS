## 1. 목적 및 배경

준비 중 화면인 설정 탭을 GONE의 카드·상태 배지 스타일로 구현합니다. 제공 이미지를 참고하되 앱 정보는 제외하고, 계정 정보와 실습실·외출·스쿨캠핑의 최근 예약·신청 활동을 제공합니다.

## 2. 사용자 시나리오

```text
사용자가 설정 탭에 진입한다
→ 계정 정보와 인증 상태를 확인한다
→ 알림 설정·문의하기 메뉴를 확인한다
→ 최근 예약·신청 활동의 상태와 요약을 확인한다
→ 활동을 탭하면 대응 기능 화면으로 이동한다
→ 로그아웃 확인 UI를 확인한다
```

## 3. 화면 및 UX

- 상단에 `설정` 보조 제목과 `계정 및 활동` 제목을 표시합니다.
- 계정 카드에는 이니셜 아바타, 이름, 학적, 인증 상태 배지를 표시합니다.
- 설정 메뉴는 알림 설정과 문의하기로 구성하며 앱 정보는 표시하지 않습니다.
- 최근 활동은 실습실 예약·외출 신청·스쿨캠핑 예약의 최신 상태·날짜·요약을 표시하고, 없을 때는 컴팩트 빈 상태를 표시합니다.
- 활동을 탭하면 해당 기능 탭으로 이동합니다.
- 로그아웃은 확인 대화상자만 제공하며 실제 인증 세션은 종료하지 않습니다.
- 상태 텍스트·VoiceOver·44pt 터치 영역·Dynamic Type·다크 모드를 고려합니다.

## 4. 데이터 및 아키텍처

```text
AppTabView → SettingsView → SettingsViewModel
→ FetchSettingsOverviewUseCase → SettingsRepository
→ MockSettingsRepository (이번 작업) / RemoteSettingsRepository (향후)
```

- `SettingsView`는 UI와 탭 이동 입력만 담당합니다.
- `SettingsViewModel`은 로딩·성공·실패 상태와 로그아웃 확인 UI 상태를 관리합니다.
- 설정 전용 `SettingsOverview`, `SettingsProfile`, `RecentActivity` 모델을 둡니다.
- 실제 알림 권한, 문의 채널, 로그아웃 토큰 폐기, 최근 활동 API는 백엔드 명세 확정 후 연결합니다.

## 5. 작업 목록

- [ ] 설정 도메인 모델·Repository·UseCase·ViewModel을 구성한다.
- [ ] 계정 카드, 설정 메뉴, 최근 활동 UI와 빈/오류 상태를 구현한다.
- [ ] 최근 활동의 기능 탭 이동과 로그아웃 확인 UI를 구현한다.
- [ ] ViewModel 단위 테스트와 접근성·다크 모드·상태 QA를 수행한다.

## 6. 완료 기준

- [ ] 설정 탭에서 준비 중 화면이 보이지 않는다.
- [ ] 앱 정보 메뉴를 제외한 계정·메뉴·최근 활동 UI가 표시된다.
- [ ] 활동 유형·요약·상태와 빈 상태를 지원한다.
- [ ] 활동 선택 시 대응 기능 탭으로 이동한다.
- [ ] 실제 세션 종료 없이 로그아웃 확인 UI를 제공한다.

## 7. 특이 사항 / 기술 검토

- 최근 활동은 목 데이터 기반 UI 범위이며 기능별 Repository를 직접 결합하지 않습니다.
- 실제 로그아웃은 인증·루트 라우팅 영향이 있어 이번 범위에 포함하지 않습니다.
