# 선도부 외출 경로 모니터링 계획서

> **상태**: 개발 진행 중
> **작성일**: 2026-08-24
> **작업 번호**: #32
> **관련 이슈**: [#32](https://github.com/GBSW-ReMake/GONE-iOS/issues/32)
> **브랜치**: `feat/32-outing-route-monitoring`

## 1. 목적 및 배경

학생이 외출을 시작한 뒤, 학생 프로필의 역할에 `선도부`가 포함되어 있으면 선도부 학생이 외출 현황을 확인할 수 있도록 한다. 외출 목록에서 외출 중인 학생을 확인하고 상세 화면에 학생의 프로필 사진, 시작 지점, 현재까지의 이동 경로, 종료 지점을 표시한다.

제공된 이미지 기준으로 외출 목록 화면, 외출 중 경로 화면, 경로가 누적된 화면, 복귀 완료 화면의 흐름을 구현한다. 지도는 시스템 다크 모드와 관계없이 화이트 스타일로 표시하고, 확대·축소가 가능하도록 한다.

학생이 외출 중인 동안에는 학생의 위치를 선도부에게 실시간 공유한다. 외출 시작 시 위치 공유를 시작하고, 복귀 완료·외출 취소·외출 만료 시 즉시 공유를 종료한다. 선도부 화면은 최신 위치와 누적 경로를 수신해 지도에 갱신한다.

## 2. 사용자 시나리오

```text
학생이 승인된 외출을 시작한다
→ 외출 상태가 외출 중으로 변경되고 위치 공유를 시작한다
→ 선도부 역할을 가진 학생의 외출 화면에 외출 학생 목록이 표시된다
→ 목록에서 학생을 선택한다
→ 상세 화면에서 프로필 사진, 외출 시작 지점, 이동 경로, 현재 위치를 확인한다
→ 지도를 확대·축소해 세부 경로를 확인한다
→ 학생이 이동할 때마다 최신 위치와 경로가 선도부 화면에 갱신된다
→ 학생이 외출을 종료/복귀 완료한다
→ 학생 위치 공유와 경로 수집을 중지하고 마지막 좌표를 종료 지점으로 표시한다
→ 지도와 상태에 `도착`을 표시한다
```

## 3. 화면 및 UX

### 선도부 외출 목록

- `roles`에 `선도부`가 포함된 학생 계정에서만 선도부용 외출 현황 화면을 노출한다.
- 기존 학생 본인의 외출 신청 목록과 구분되는 `외출 학생 관리` 목록을 표시한다.
- 외출 중인 학생은 학생 이름, 학번, 외출 시간, 상태 배지를 확인할 수 있다.
- 외출 중인 항목을 탭하면 경로 상세 화면으로 이동한다.
- 외출 중 학생의 최신 위치 수신 시 목록의 위치 공유 상태와 갱신 시각을 업데이트한다.
- 외출 중인 학생이 없을 때는 빈 상태와 위치 공유 상태 안내를 제공한다.

### 경로 상세 지도

- 지도는 `MapKit`을 사용하고 `.standard` 기반의 라이트 지도 스타일을 유지한다.
- 지도는 시작 지점과 현재/종료 지점을 표시한다.
- 이동 경로는 GONE 메인 컬러의 선으로 표현한다.
- 현재 위치 마커에는 학생 프로필 사진을 원형으로 표시한다.
- 프로필 사진 위에 음표, 음악 아이콘 등 불필요한 장식은 표시하지 않는다.
- 사용자 기본 조작으로 확대·축소·이동을 허용하고, 필요하면 현재 경로 전체 보기 버튼을 제공한다.
- 외출 중에는 `외출 중` 상태와 위치 갱신 시각을 표시한다.
- 학생 이동 시 선도부 화면의 현재 위치 마커와 누적 경로를 실시간으로 갱신한다.
- 복귀 완료 후에는 이동 경로를 고정하고 마지막 좌표에 종료 마커와 `도착` 라벨을 표시한다.

### 상태 피드백 및 접근성

- 상태를 색상만으로 구분하지 않고 `외출 중`, `도착` 텍스트를 함께 제공한다.
- 지도 마커와 경로에는 VoiceOver 설명을 제공한다.
- 위치 권한이 없거나 위치 갱신에 실패하면 원인과 확인 방법을 안내한다.
- 학생에게는 위치 권한 및 위치 공유 중임을 명확히 안내하고, 외출 상태가 아닐 때는 공유하지 않는다.
- 선도부에게는 위치 공유 대상·마지막 갱신 시각·연결 끊김 상태를 표시한다.
- 프로필 사진이 없으면 기존 앱의 이니셜 기반 대체 표현을 사용한다.

## 4. 데이터 및 아키텍처

```text
OutingView
→ LeaderOutingListView
→ OutingRouteDetailView
→ OutingViewModel
→ OutingRepository / OutingLocationRepository / RealtimeOutingLocationRepository
→ MockOutingRepository / MockOutingLocationRepository
```

### Domain

- `OutingRequest.Status`에 `outing`과 `completed` 상태를 추가한다.
- 외출 경로를 표현하는 `OutingRoute`를 추가한다.
  - 시작 좌표
  - 현재 또는 종료 좌표
  - 누적 좌표 배열
  - 위치 갱신 시각
  - 경로 상태(외출 중/도착)
- 학생 프로필 사진은 현재 프로젝트의 프로필 데이터 흐름과 충돌하지 않도록 `OutingStudent`에 선택적 이미지 식별자 또는 이미지 데이터를 추가하는 방안을 검토한다.

### Repository / UseCase

- 기존 `OutingRepository`의 신청·승인 흐름은 유지한다.
- 위치 조회 및 경로 갱신은 `OutingLocationRepository` 프로토콜로 분리한다.
- 학생 단말의 위치를 선도부에게 전달하는 실시간 스트림은 `RealtimeOutingLocationRepository` 추상화로 분리한다. 구현체는 서버 WebSocket, SSE 또는 프로젝트에서 확정한 실시간 전송 방식으로 교체할 수 있어야 한다.
- 선도부 외출 현황 조회, 경로 조회, 외출 종료 처리는 ViewModel이 Repository를 직접 조합하지 않도록 UseCase로 분리한다.
- 위치 공유 세션은 학생의 외출 시작 이벤트에서만 시작하고, 복귀 완료·취소·만료·권한 철회·오류 발생 시 종료한다.
- 실제 서버 및 위치 공유 API가 확정되지 않았으므로 1차 구현은 Mock 실시간 스트림으로 위치 갱신·경로 누적·연결 끊김 상태를 검증한다.
- 실제 Core Location 권한 요청, 백그라운드 위치 수집, 서버 전송은 API와 개인정보 정책 확정 후 별도 작업으로 연결한다.
- 실시간 전송에는 학생 식별자, 외출 식별자, 위도·경도, 측정 시각, 공유 세션 상태만 사용하고, 권한 없는 계정에는 스트림을 제공하지 않는다.

### Presentation

- `OutingView`에서 학생 일반 화면과 선도부 화면을 역할에 따라 분기한다.
- 역할 판별은 현재 홈 Mock 데이터의 `roles`에 있는 `선도부`를 기준으로 하되, 전역 세션에서 프로필 역할을 제공하는 구조가 확인되면 해당 흐름을 우선 사용한다.
- `Map`/`MapPolyline`과 `MapMarker`를 사용해 경로를 표시한다.
- 지도 관련 변환, 상태 문구, 선택된 외출 학생 상태는 ViewModel 또는 별도 Presentation 모델에서 관리하고 View에는 비즈니스 로직을 두지 않는다.

- [ ] 외출 중인 학생 목록에서 학생을 선택해 경로 상세 화면으로 진입할 수 있다.
- [ ] 상세 화면에 프로필 사진, 시작 지점, 현재 위치, 누적 경로가 표시된다.
- [ ] 학생이 외출 중일 때만 위치 공유 세션이 활성화되고 선도부에게 최신 위치가 실시간 전달된다.
- [ ] 선도부 화면에서 최신 위치 마커와 누적 경로가 위치 갱신에 맞춰 업데이트된다.
- [ ] 프로필 사진 위에 음표나 음악 아이콘이 표시되지 않는다.

- [ ] 경로는 GONE 메인 컬러로 표시된다.
- [ ] 외출 종료 시 경로 업데이트가 중지되고 종료 지점에 좌표와 `도착`이 표시된다.
- [ ] 외출 종료·취소·만료·권한 철회·공유 오류 시 위치 공유가 종료된다.
- [ ] 위치 권한 거부·위치 오류·실시간 연결 끊김·빈 목록 상태가 안내된다.
- [ ] ViewModel 테스트와 시뮬레이터 QA 결과가 문서에 기록된다.

## 7. 결정 필요 사항

- 선도부가 확인할 수 있는 범위: 전체 외출 학생인지, 담당 학년/반인지
- 실제 위치 데이터 수신 API, 갱신 주기, 위치 보관 기간
- 실시간 위치 전달 방식(WebSocket/SSE 등), 갱신 주기, 재연결 정책
- 위치 공유 동의 문구, 선도부 열람 권한, 감사 로그 및 위치 데이터 삭제 정책
- 외출 종료를 학생이 직접 누르는지, 서버/선도부가 종료 처리하는지
- 학교 기준 좌표 및 경로 표시의 최대 범위
- 실기기 위치 권한 및 백그라운드 위치 테스트 가능 여부
