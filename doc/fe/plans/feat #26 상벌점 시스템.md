## 1. 목적 및 배경

학생은 홈에서 상점·벌점·현재 점수와 역할을 확인하고, 선생님은 기존 스쿨캠핑 탭을 상벌점 탭으로 전환해 학생 검색부터 점수 발급, 발급 내역, 개인 기준 통계를 한 흐름에서 처리할 수 있도록 한다.

이번 단계는 현재 iOS 프로젝트의 Mock 데이터 기반 UI/상태 흐름을 완성하는 범위로 진행한다. 실제 API 계약이 확인되지 않았으므로 Repository protocol과 Mock 구현을 먼저 두고, API 연동은 후속 작업으로 분리한다.

## 2. 사용자 시나리오

### 학생

```text
학생이 홈에 진입한다
→ 프로필 요약 아래 상벌점 상태 영역에서 상점·벌점·현재 점수를 확인한다
→ 기존 역할 정보와 함께 자신의 역할을 확인한다
```

### 선생님

```text
선생님이 하단 상벌점 탭에 진입한다
→ 점수발급 탭에서 발급 대상자 추가를 선택한다
→ 학번 또는 이름으로 학생을 검색하고 대상자를 추가한다
→ 상점/벌점, 발급 항목, 메모를 입력한다
→ 발급 대상자 명단을 확인하고 점수 발급을 실행한다
→ 완료 화면에서 발급 결과를 확인한 뒤 확인한다
→ 발급 내역 탭에서 전체/상점/벌점/기간 필터로 내역을 확인한다
→ 통계 탭에서 내 기준 요약과 월별 발급 현황을 확인한다
```

## 3. 화면 및 UX

### 화면 구성

- 학생 홈: 기존 `ProfileSummaryCard`와 분리된 `PointSummaryCard`
- 선생님 탭바: `스쿨캠핑` 대신 `상벌점` 탭, 상벌점 아이콘은 제공된 `jam_medal-f.svg`를 앱 에셋으로 사용
- 상벌점 메인: `점수발급`, `발급 내역`, `통계` 세그먼트
- 학생 검색: 시트 또는 전체 화면 검색, 학번/이름 입력, 검색 결과에서 대상자 추가
- 발급 폼: 대상 학생, 상점/벌점 선택, 발급 항목 선택, 메모 입력, 대상자 추가
- 발급 완료: 성공 상태, 발급 명단, 취소/확인 액션
- 발급 내역: 필터 칩, 발급 카드, 상세 진입 affordance
- 통계: 내 기준 요약 카드, 최근 5개월 막대 차트, 학생별 누계/항목별/교사별 메뉴

### 상태

- 정상: Mock 데이터와 입력 결과가 화면에 반영됨
- 로딩: Repository 조회 중 ProgressView 또는 비활성 상태
- 빈 상태: 대상자 없음, 발급 내역 없음, 통계 데이터 없음
- 오류: 조회/발급 실패 메시지와 재시도
- 입력 검증: 대상자 미선택, 항목 미선택, 점수 유효성 부족 시 발급 버튼 비활성화

### 접근성

- 점수 값은 `상점 15점, 벌점 3점, 현재 점수 12점`처럼 의미 단위로 읽히도록 설정
- 검색 결과 추가/삭제, 발급 완료, 오류를 VoiceOver 알림으로 제공
- 버튼 터치 영역 최소 44pt 유지
- Dynamic Type에서 카드와 필터가 잘리지 않도록 세로 스크롤 및 유연한 레이아웃 사용
- 라이트/다크 색상 대비는 기존 DesignSystem 토큰을 우선 사용

## 4. 데이터 및 아키텍처

### 데이터 흐름

- Model: `PointSummary`, `Student`, `PointIssueDraft`, `PointIssueRecord`, `PointStatistics`
- Repository: `PointRepository` protocol과 `MockPointRepository`
- UseCase: 학생 검색, 발급 대상 조회/발급, 발급 내역 조회, 개인 통계 조회
- ViewModel: 상벌점 탭 상태, 검색 시트 상태, 발급 폼 검증/완료 상태, 필터 상태
- View: 표시와 사용자 이벤트 전달만 담당

### 역할 및 탭 정책

- 학생: 홈·실습실·외출·스쿨캠핑·마이 유지
- 선생님: 홈·실습실·외출·상벌점·마이로 구성
- `AppTab`은 역할별 가시 탭을 명시적으로 관리하고, 설정의 활동 이동도 역할별 탭에 맞게 연결
- 상벌점 화면은 선생님 전용이며 학생이 직접 접근할 수 없도록 한다

### 외부 의존성 및 결정 필요 항목

- 실제 API endpoint, 인증 토큰, 학생 검색 권한, 발급 권한은 백엔드 명세 확인 후 Repository 구현에 반영
- 통계 범위는 전체 교사 기준이 아니라 현재 로그인한 선생님이 발급한 기록 기준으로 Mock 모델링
- 제공된 SVG는 탭 아이콘 에셋으로 등록하되, Xcode 에셋 동기화 방식에 맞춰 파일명은 `PointTabIcon`으로 통일

## 6. 완료 기준

- [ ] 학생 홈에 상점·벌점·현재 점수·역할이 레퍼런스와 유사하게 표시된다.
- [ ] 선생님 로그인 시 하단 탭에 스쿨캠핑 대신 상벌점이 표시된다.
- [ ] 학생 검색, 대상자 추가/삭제, 상점/벌점 선택, 항목/메모 입력이 동작한다.
- [ ] 발급 버튼 활성화 조건과 완료 화면의 발급 명단이 일치한다.

- [ ] 통계가 현재 선생님 기준으로 표시되고 요약·월별 현황이 확인된다.
- [ ] 정상·로딩·빈·오류·입력 검증 상태를 확인한다.
- [ ] ViewModel 핵심 상태 전환 단위 테스트를 추가한다.
- [ ] `xcodebuild` 또는 사용 가능한 Xcode 검증 환경에서 빌드/테스트하고 결과를 보고한다.

## 7. 특이 사항 / 기술 검토

- 현재 `AccountRole`은 외출 기능에서 이미 역할별 분기를 사용하고 있으므로 탭 정책도 동일한 역할 값을 재사용한다.
- 기존 홈 모델의 `rewardPoints`, `penaltyPoints`, `totalPoints`를 재사용해 학생 카드 변경 범위를 최소화한다.
- 이미지 레퍼런스의 시각 요소는 기존 GONE 색상·간격 토큰으로 재구성하고, 외부 이미지 생성이나 과도한 디자인 시스템 확장은 하지 않는다.
- 계획 승인 전에는 GitHub 이슈와 브랜치를 만들지 않는다.
