# 인증 API 연동 최종 개발 보고서

## 개요

로그인과 회원가입 전체 흐름을 개발 서버에 연결하고, 전화번호 인증부터 이름·프로필 설정 및 홈 진입까지 완료했습니다.

## 변경 사항

- Moya 기반 인증 Target 및 네트워크 클라이언트 구성
- 개발 서버 `https://gone-dev.gbsw.hs.kr` 연결
- 로그인 API 연동 및 성공 전 화면 전환 차단
- 회원가입 API 연동
- SMS 인증번호 발급·검증 연동
- 인증번호 유효시간 5분, 재발송 쿨다운 30초, 인증 실패 최대 5회 반영
- 백엔드 오류 코드와 메시지 기반 사용자 안내
- 이름 조회 및 변경 API 연동
- 프로필 이미지 presigned URL 발급 → R2 업로드 → 업로드 확정 연동
- 프로필 사진을 건너뛸 수 있도록 처리
- 회원가입 성공 후 별도 로그인 없이 저장된 토큰으로 홈 진입
- 인증번호 버튼 상태를 `인증번호 받기` → `N초 후 재발급` → `재발급 받기`로 개선

## 구조

- View: 입력 및 화면 상태 표현
- ViewModel: 인증 단계, 로딩, 타이머, 오류 상태 관리
- UseCase: 로그인·회원가입·프로필 완료 흐름 조합
- Repository: Moya 및 URLSession 기반 서버/R2 데이터 접근
- SessionStore: Keychain 토큰 저장
