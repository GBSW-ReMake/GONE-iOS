## 구현 요약

외출 탭의 플레이스홀더를 외출 신청·승인 대기·외출 시작·외출 중·복귀 상태를 확인할 수 있는 SwiftUI 플로우로 교체했습니다. 앱은 라이트 색상을 고정해 다크 모드에서도 동일한 디자인 색상을 사용합니다.

## 구현된 기능

- [x] 외출 탭 진입 화면, 사용자 제공 외출 이미지, 신청 폼 및 신청 완료 카드
- [x] 이번 달로 제한한 한국어 날짜 선택과 흰색 날짜·시간 선택 시트
- [x] `오전/오후 h:mm` 형식의 시간 표기 및 카드 행 정렬
- [x] 신청 완료·승인 대기·외출 가능·외출 중·복귀 가능 상태 화면
- [x] 외출 시작·복귀의 1.5초 길게 누르기와 반복 충전형 햅틱 피드백
- [x] 외출 중 위치 공유를 나타내는 파동 애니메이션
- [x] 승인 카드에서 대기·외출 가능 상태 미리보기 제공
- [x] 외출·실습실 비활성 신청 버튼의 연한 파란색 CTA 상태 보정
- [x] 라이트 테마 고정 및 외출 전용 색상 토큰 추가

## 아키텍처

- `OutingRequest`, `OutingDraft`가 외출 도메인 상태를 표현합니다.
- `OutingRepository`로 데이터 접근을 추상화하고, 현재는 `MockOutingRepository`가 상태 전환을 제공합니다.
- `OutingViewModel`은 신청·취소·외출 시작·복귀 완료 및 미리보기 상태 전환을 관리합니다.
- `OutingView`는 입력·표시·길게 누르기 인터랙션을 담당합니다.

## 알려진 제한사항

- 실제 외출 API와 승인 상태, 위치 공유 서버 계약이 없어 현재는 Mock 상태로 동작합니다.
- 위치 공유는 화면 피드백과 상태 표현까지만 구현됐으며 Core Location·선도부 실시간 공유 연동은 API 계약 후 연결해야 합니다.
- 외출·복귀 햅틱 강도는 기기별 시스템 제약에 따라 차이가 있을 수 있어 실기기 확인이 필요합니다.
- 작업 시작 전부터 존재하던 AccentColor·탭 아이콘·`HomeViewModel.swift`·원본 이미지 폴더 변경은 이 PR에 포함하지 않습니다.
