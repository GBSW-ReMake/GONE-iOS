## 구현 요약

학생은 홈에서 상벌점 현황을 확인하고, 선생님은 상벌점 탭에서 학생 검색·점수 발급·완료 결과·발급 내역·개인 기준 통계를 확인할 수 있도록 Mock 기반 iOS 플로우를 구현했습니다.

## 구현된 기능

- [x] 학생 홈 상점·벌점·현재 점수·역할 카드
- [x] 역할별 탭바: 학생은 스쿨캠핑, 선생님은 상벌점
- [x] 제공 SVG 기반 상벌점 탭 아이콘
- [x] 학번/이름 학생 검색 및 대상자 추가·삭제
- [x] 상점/벌점, 점수, 발급 항목, 메모 입력
- [x] 발급 완료 화면 및 발급 명단
- [x] 발급 내역 및 상점/벌점 필터
- [x] 현재 선생님 기준 통계 요약
- [x] PointSystemViewModel 핵심 상태 테스트
- [ ] 실제 API 연동 (백엔드 명세 미확정)

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
