## 구현 요약

스쿨캠핑 탭에 월간 예약 달력, 예약 신청 폼, 예약 완료 카드 및 참여 명단 관리 흐름을 구현했습니다. 학생·담당 선생님은 검색 시트에서 선택하며, 예약 완료 후에도 명단을 확인하고 수정할 수 있습니다.

## 구현된 기능

- [x] 예약 가능·불가·내 예약 상태를 표현하는 월간 달력과 범례
- [x] 날짜 선택, 담당 선생님 검색, 학생 검색·추가·삭제가 가능한 예약 폼
- [x] 예약 완료 카드, 달력 보기, 예약 취소 및 내 예약 상태 갱신
- [x] 참여 명단 조회·수정 화면과 담당 선생님 변경
- [x] 최대 8명 제한, 중복 학생 추가 방지, 유효성 기반 CTA 상태
- [x] 예약 수정 저장 시 발생하던 `EXC_BAD_ACCESS` 크래시 방지

## 크래시 원인 및 조치

명단 수정 저장 시 편집 화면 전환과 예약 상태 갱신이 같은 렌더링 트랜잭션에 겹치면서 SwiftUI가 이전 예약 카드의 배열·문자열 상태를 다시 읽어 `EXC_BAD_ACCESS`가 발생했습니다.

- 예약 엔티티를 동일한 참조 객체로 유지하고 변경 값을 적용하도록 조정했습니다.
- 수정 요청은 편집 화면과 참여 명단 화면이 닫힌 뒤 처리하도록 분리했습니다.
- 변경 사항이 없는 저장은 데이터 갱신 없이 편집 화면만 닫습니다.
- 실제 선생님 변경 후 저장하는 UI 회귀 테스트를 추가했습니다.
