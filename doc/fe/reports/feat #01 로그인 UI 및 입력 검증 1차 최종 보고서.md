## 구현 요약

피그마 로그인 화면을 SwiftUI로 구현하고, MVVM 기반 입력 상태·유효성 검증과 GONE 공용 디자인 시스템 기초를 추가했습니다.

## 구현된 기능

- [x] GONE 로고, 소개 문구, 아이디·비밀번호 입력 필드, 회원가입 링크, 로그인 CTA 구현
- [x] 아이디·비밀번호 미입력 시 CTA 비활성화 및 입력 오류 안내
- [x] 회원가입 텍스트만 동작하는 최소 44pt 터치 영역 적용
- [x] SF Pro 기반 공용 폰트·색상·버튼·밑줄 입력 필드 구성
- [x] 라이트·다크 모드에서 동일하게 보이는 placeholder 색상 적용
- [x] `LoginView`와 `LoginViewModel` 분리 및 입력 검증 단위 테스트 추가
- [ ] 인증 API 요청, Keychain 세션 저장, 성공 후 화면 전환 (API 명세 미확인)

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 인증 API | API 명세 기반 연동 | 미구현 | Notion API 명세 접근 권한이 없어 계약을 확인할 수 없음 |
| Keychain 세션 | 토큰 저장 | 미구현 | 응답 토큰 구조와 갱신 정책 미확정 |
| 로딩 상태 | 로그인 요청 중 표시 | 미구현 | 실제 요청 계층 구현 보류 |
