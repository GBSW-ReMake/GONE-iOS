## 구현 요약

학생은 이번 주 안에서 외출 시간을 신청하고 담당 선생님을 지정할 수 있으며, 선생님은 역할별 화면에서 신청을 확인하고 승인 또는 거절할 수 있도록 구현했습니다. 시간 프리셋·중복 검증·검색 시트·승인 상태 필터를 포함해 신청부터 검토까지의 UI 흐름을 완성했습니다.

## 구현된 기능

- [x] 이번 주 날짜만 선택 가능한 외출 신청
- [x] 08:40~20:30 시간 제한 및 출발·복귀 시간 검증
- [x] 같은 날짜의 겹치는 외출 신청 차단 및 인접 시간 신청 허용
- [x] 점심·저녁 프리셋과 직접 시간 설정
- [x] 외출 사유·담당 선생님 필수 입력
- [x] 하단 시트 기반 선생님 검색과 `+` 선택
- [x] 학생/선생님 계정 역할별 외출 화면 분리
- [x] 선생님 외출 목록·상세·수락·거절 사유 입력
- [x] 승인 요청·승인 완료·거절됨 필터
- [x] 목록 카드 패딩·상태 배지·상세 버튼 UX 정리

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 점심·저녁 프리셋 시간 | 정책 확정 후 반영 | Mock 정책값으로 구현 | 실제 운영 시간 API 연동 전 UI 검증 목적 |
| 선생님 검색 | 이름과 역할 표시 | 검색 결과에 이름, 선택 안내를 표시하고 선택 후 폼에는 이름만 표시 | 사용자 요청에 따라 `teacher` 텍스트를 신청 상세에서 제거 |
| 교사 승인 목록 | 목록과 상세 제공 | 상태 필터와 카드 내부 상세 이동까지 구현 | 신청이 많아질 때 빠르게 상태별 조회 가능하도록 확장 |

## 알려진 제한사항

- 현재 데이터는 `MockOutingRepository` 메모리 데이터이며 앱 재실행 시 초기화됩니다.
- 점심·저녁 프리셋 시간은 실제 학교 정책값으로 교체해야 합니다.
- 실제 인증 API의 학생/선생님 권한과 선생님 검색 API 연동이 필요합니다.
- 현재 실행 환경은 Xcode가 아닌 CommandLineTools가 활성화되어 있어 `xcodebuild` 및 시뮬레이터 QA를 진행하지 못했습니다.
