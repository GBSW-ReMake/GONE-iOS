## 구현 요약

선생님 실습실 탭을 학생용 예약 신청 화면과 분리해, 학생들의 실습실 신청 현황을 층·날짜별로 조회하고 예약 상세를 확인할 수 있는 화면으로 구현했다.

## 구현된 기능

- [x] 교사용 실습실 현황 Model / Repository / UseCase / ViewModel
- [x] 층·날짜 선택 및 층별 실습실 카드 목록
- [x] 야자시간·방과후 이용 시간 태그
- [x] 예약·미예약 상태 카드
- [x] 예약 카드 상세 페이지
- [x] 학생 실습실 예약 흐름 유지
- [x] 선생님 상벌점 `PointSystemView` 탭 및 `AppTab.points` 보정
- [x] 교사용 현황 ViewModel 단위 테스트
- [x] 상벌점 탭과 동일한 층 선택 영역 배경색 적용
- [x] 실습실 현황 제목과 첫 카드 사이 간격 조정
- [x] 예약 상세 콘텐츠 왼쪽 정렬 및 섹션 간격 조정
