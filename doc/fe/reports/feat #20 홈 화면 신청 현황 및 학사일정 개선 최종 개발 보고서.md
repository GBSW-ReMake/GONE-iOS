## 구현 요약

홈 탭에서 더 이상 제공하지 않는 상점·벌점·현재 점수를 제거하고, 월별 학사일정 UI와 신청 현황의 기능별 이동 흐름을 추가했습니다. 학사일정은 백엔드 연동 전 목 데이터로 구성했으며, 카드·월 이동·신청 현황 탭 전환의 움직임을 자연스럽게 보완했습니다.

## 구현된 기능

- [x] 사용자 요약 카드에서 상점, 벌점, 현재 점수 제거
- [x] 시간표와 급식 사이에 월별 세로형 학사일정 카드 추가
- [x] 이전/다음 월 이동 및 방향별 슬라이드·페이드 전환
- [x] 일정 없는 달의 컴팩트 빈 상태 UI
- [x] 실습실·외출·스쿨캠핑 신청 상태를 홈 신청 현황에 반영
- [x] 신청 현황 카드 선택 시 해당 기능 탭으로 이동
- [x] 외출 신청 내역이 있는 경우 기존 신청 목록을 유지하도록 재로딩 방지
- [x] 신청 현황 카드의 축소·페이드 전환 피드백과 중복 탭 방지
- [x] 학사일정 월 이동 ViewModel 단위 테스트 추가

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 사용자 요약 | 상점만 제거 | 상점·벌점·현재 점수 모두 제거 | 개발자 검토에서 불필요한 점수 정보를 숨기도록 범위 조정 |
| 학사일정 카드 | 세로 카드 목록 | 한 줄 날짜·제목 기반의 컴팩트 카드 | 카드 높이와 스크롤 길이를 줄이기 위함 |
| 화면 전환 | 기본 탭 이동 | 탭 선택 완화 애니메이션, 월 이동 슬라이드, 신청 카드 피드백 | 화면 전환의 단절감을 줄이기 위함 |

## 알려진 제한사항

- 학사일정은 UI 검토용 목 데이터이며 실제 백엔드 API, 월별 조회, 오류 처리와 캐시 정책은 포함하지 않습니다.
- 실제 iOS Simulator 또는 실기기에서 화면 전환 속도, Dynamic Type, 다크 모드, VoiceOver 검증이 필요합니다.
- 실습실·외출·스쿨캠핑 상태는 현재 목 Repository와 화면 상태를 기반으로 표시합니다.
