## 구현 요약

홈 화면의 목 데이터를 개발 서버 API 기반 데이터로 교체하고, 홈 재진입·새로고침·시간표 스와이프·신청 현황의 사용자 경험을 개선했습니다.

## 구현된 기능

- [x] 프로필, 상벌점, 시간표, 급식 API 연동
- [x] 외출·스쿨캠핑 신청 현황 API 연동
- [x] 신청 내역이 없을 때 빈 상태 표시
- [x] 홈 재진입 시 기존 데이터 유지
- [x] 당겨서 새로고침 시 대시보드 API 재요청
- [x] 최초 진입 로딩 UI 개선
- [x] 시간표 전체 영역 좌우 스와이프 지원
- [x] 홈 섹션 아이콘 에셋 적용
- [ ] 학사일정 API 연동 (개발 서버 명세 미제공)

## 계획서 대비 변경 사항

| 항목 | 실제 구현 | 비고 |
|---|---|---|
| 학사일정 | 빈 배열로 표시 | 백엔드 API 경로·응답 형식 필요 |
| 실습실 신청 현황 | 신청 내역 없음 상태 표시 | 개발 서버 명세에 홈용 실습실 신청 API 없음 |
| 새로고침 | 기존 화면 유지 후 API 재요청 | 중앙 오버레이·배경 흐림 제거 |

## 알려진 제한사항

- 학사일정 API가 개발 서버 명세에 없어 현재 데이터를 표시하지 않습니다.
- 실습실 신청 API가 제공되면 목 빈 상태를 실제 데이터 연동으로 교체해야 합니다.
- 실제 계정·네트워크 환경에서 API 응답과 실기기 제스처 QA가 필요합니다.
