## 구현 요약

회원가입 흐름을 5단계로 확장했습니다. 전화번호 인증 다음에 학번과 이름을 각각 입력하고, 선택적으로 프로필 사진을 설정할 수 있습니다. 공통 밑줄 입력 폼은 포커스 시 라벨과 밑줄을 메인 컬러로 함께 표시합니다.

## 구현된 기능

- [x] 회원가입 5단계 진행 표시와 단계 전환
- [x] 학번·이름 독립 입력 폼 및 두 값 필수 검증
- [x] 선택형 `PhotosPicker` 프로필 사진 선택과 원형 미리보기
- [x] 사진 읽기 실패 시 사진 없이 계속할 수 있는 오류 안내
- [x] 입력 폼 포커스·오류 상태별 라벨 색상 우선순위
- [x] 회원가입 ViewModel 단위 테스트 추가
- [ ] 프로필 이미지 업로드 및 실제 회원가입 API 연동 (API 계약 미확정)

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 학번·이름 | 별도 입력 폼 | 학번·이름 각각 독립된 밑줄 폼 | 개발자 변경 요청 반영 |
| 프로필 이미지 | 선택형 사진 설정 | `PhotosPicker`와 로컬 미리보기 | 업로드 API가 미확정이라 전송은 제외 |
