## 구현 요약

학생이 홈에서 학적·상벌점·역할, 오늘 시간표·급식, 실습실·외출·스쿨캠핑 신청 현황을 확인할 수 있도록 홈 대시보드를 구현했습니다.

Figma 홈 화면을 기준으로 카드 정보 구조와 제공 PNG·SVG 에셋을 적용했으며, 시간표와 급식은 좌우 스와이프로 항목을 한 장씩 전환할 수 있습니다.

## 구현된 기능

- [x] 사용자 인사말, 학적·상벌점·현재 점수 요약 카드
- [x] 역할별 색상 칩(선도부·방송부·iOS 전공동아리)
- [x] 오늘 시간표 카드와 항목별 페이지 카운터
- [x] 오늘 급식 카드, 배식 시간·2열 메뉴·칼로리 표시
- [x] 시간표·급식 카드의 좌우 스와이프 전환 및 방향별 애니메이션
- [x] 실습실·외출·스쿨캠핑 신청 현황 카드와 상태 배지
- [x] 제공 PNG 일러스트 3종 및 SVG 탭 아이콘 5종 등록·연결
- [x] `TabView` 기반 홈·실습실·외출·스쿨캠핑·설정 탭 바
- [x] GONE AppIcon 복구 및 AppIcon 세트 연결
- [x] `HomeViewModel` 성공·실패 상태 전환 단위 테스트 추가
- [ ] 실제 홈 대시보드 API 연동 (API 계약 미확정)
- [ ] 실습실·외출·스쿨캠핑·설정 상세 기능 (후속 기능 범위)

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 시간표 전환 | 카드형 시간표 | 좌우 스와이프·방향별 애니메이션 | 세로 전환이 전체 화면 스크롤과 충돌해 UX 피드백 반영 |
| 급식 데이터 | 단일 급식 카드 | 3개 Mock 급식 항목·페이지 전환 | 급식 카드 전환 UI 검증을 위한 임시 데이터 구성 |
| 탭 아이콘 | 원본 아이콘 적용 | 원본 SVG 템플릿 에셋 등록 | 선택 상태에 앱 브랜드 tint를 적용하기 위함 |

## 알려진 제한사항

- API 명세가 없어 홈 데이터는 `MockHomeDashboardRepository`가 제공합니다.
- Mock 급식 3개 항목은 스와이프 UI 확인용이며, 실제 급식 API 계약 후 대체해야 합니다.
- Xcode 전체가 설치된 환경에서 빌드·XCTest·시뮬레이터 UI QA를 수행해야 합니다.
- 현재 작업 트리의 AppIcon 외 AccentColor·탭 아이콘 설정 변경, `HomeViewModel.swift` 변경, 원본 이미지 폴더는 본 작업 커밋에 포함하지 않았습니다.
