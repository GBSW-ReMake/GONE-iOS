## 구현 요약

앱을 실행하면 스플래시 화면을 표시한 뒤 학생 또는 선생님 로그인 유형을 선택하도록 흐름을 변경했습니다. 로그인 화면에서는 역할 선택 컨트롤을 제거하고, 뒤로 가기 버튼으로 로그인 유형을 다시 선택할 수 있게 했습니다.

## 구현된 기능

- [x] GONE 로고를 표시하는 스플래시 화면을 추가했습니다.
- [x] 로고 축소·페이드 전환과 Reduce Motion 대응을 추가했습니다.
- [x] 학생·선생님 로그인 유형 선택 화면을 추가했습니다.
- [x] 제공한 로고와 사용자 일러스트를 Asset Catalog에 추가했습니다.
- [x] 로그인 화면에서 역할 선택 세그먼트를 제거했습니다.
- [x] 선택한 역할을 로그인 자격 증명과 홈 화면 이동에 사용합니다.
- [x] 로그인 화면에 로그인 유형 선택 화면으로 돌아가는 글래스 뒤로 가기 버튼을 추가했습니다.
- [x] 로그인과 역할 선택 화면의 로고·텍스트 크기를 통일했습니다.
- [x] 교사 역할 자격 증명을 검증하는 단위 테스트를 추가했습니다.
- [ ] Simulator에서 실제 화면 전환과 접근성을 확인합니다. 런타임 설치 후 진행합니다.

## 계획서 대비 변경 사항

| 항목 | 계획 | 실제 구현 | 사유 |
|---|---|---|---|
| 로그인 유형 변경 | 역할 선택 후 로그인 | 로그인 화면의 뒤로 가기 버튼으로 역할 선택 화면에 돌아갑니다. | 잘못 선택한 로그인 유형을 바로 변경할 수 있게 했습니다. |
| 버튼 스타일 | 학생 채움·선생님 테두리 버튼 | 기존 버튼 스타일을 유지했습니다. | 화면의 기존 시각적 위계를 유지합니다. |
