## 구현 요약

기존 설정 탭 플레이스홀더를 학생 계정과 최근 예약·신청 이력을 확인할 수 있는 설정 화면으로 교체했습니다. 프로젝트 디자인 시스템을 사용해 계정 카드, 개별 메뉴 카드, 활동 필터와 활동별 카드 목록을 구성했습니다.

## 구현된 기능

- [x] Settings 도메인 모델·Repository·UseCase·ViewModel 기반 화면 상태 구성
- [x] 계정 정보 카드 및 작은 프로필 아바타 표시
- [x] 앱 정보·인증됨 표시 제거
- [x] 알림 설정·문의하기를 독립된 카드로 구성
- [x] 전체·실습실·외출·스쿨캠핑 최근 활동 필터 제공
- [x] 최근 활동을 신청 유형별 개별 카드 목록으로 표시
- [x] 활동 상태 태그 제거 및 기능 탭 이동 연결
- [x] 최근 활동 빈 상태 UI 제공
- [x] 로그아웃 확인 대화상자 UI 제공
- [x] 메뉴·활동 카드 및 필터의 세로 밀도 조정

## 설계 및 UI 반영 사항

| 항목 | 반영 내용 |
|---|---|
| 화면 구조 | View는 표시·입력 전달, ViewModel은 상태 관리, UseCase·Repository는 설정 개요 조회 책임으로 분리 |
| 최근 활동 | 단일 묶음 카드 대신 항목별 카드로 구분해 가독성과 탭 대상을 명확히 함 |
| 필터 | 둥근 사각형 선택 UI로 변경하고, 시각적 높이는 36pt·터치 영역은 44pt 이상 유지 |
| 카드 밀도 | 메뉴와 활동 카드의 세로 여백을 축소해 설정 화면의 스크롤 길이를 줄임 |
| 접근성 | 필터 선택 상태와 활동 카드 이동 힌트를 VoiceOver에 제공 |

## 알려진 제한사항

- 설정 데이터와 최근 활동은 현재 UI 검토용 Mock Repository 데이터입니다.
- 알림 설정·문의하기·로그아웃은 안내 및 확인 UI만 제공하며 실제 서비스 연동은 후속 작업이 필요합니다.
- iOS Simulator 런타임이 없어 실기기·Simulator 기반 UI 및 단위 테스트를 완료하지 못했습니다. 상세 내용은 `doc/fe/issues/issue-22-설정-ui-빌드-qa.md`를 참고합니다.
